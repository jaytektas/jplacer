# jplacer

jplacer controls pick-and-place machines: the machines that pick electronic parts from feeders and place
them on a circuit board.

!!! note "Early days"
    This version is the start of jplacer: its window, menus, preferences and self-updating. The menu
    entries for jobs and the machine are there so you can see the shape of the program, but they are
    greyed out until each feature is built. [Menus](menus.md) lists what is available now.
