# Translations

OpenPnP's translations (`src/main/resources/org/openpnp/translations*.properties`, GPL-3.0, from
https://github.com/openpnp/openpnp), as View > Language uses them: a label is shown in the chosen language when
OpenPnP's English for it (`translations.properties`) is the same as jplacer's. They travel beside the executable
(`usr/bin/translations` in the AppImage) and are read by `src/common/JPTranslations.cpp`.
