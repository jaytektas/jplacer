OpenPnP's icons (https://github.com/openpnp/openpnp, `src/main/resources/icons`,
GPL-3.0-or-later, Copyright (C) Jason von Nieda and the OpenPnP contributors), used as they are so jplacer's buttons look as OpenPnP's do. A
`_dark` file is the same icon for a dark theme.

`library.svg` (books on a shelf) and `board-source.svg` (a board with parts on it) are jplacer's own, for
a parts or packages table's Source column: drawn in the same flat style, filling their canvas so they read
at a row's height, GPL-3.0 as jplacer is.

`table-columns.svg` (a table under a tick) is jplacer's own too, for the toolbars' Columns… button that
chooses a table's columns: OpenPnP's flat 24-pixel style and its action green (`_dark` the brighter green
of its dark icons), GPL-3.0 as jplacer is.

`jaytek-logo.png` is the Jaytek mark for the About box (Help ▸ About jplacer), the same file jayecu Studio's About
box shows: made from its 1024-pixel artwork at the size the box draws it (400 pixels wide), as the box draws a
picture one pixel for each.
