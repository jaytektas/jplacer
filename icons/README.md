OpenPnP's icons (https://github.com/openpnp/openpnp, `src/main/resources/icons`,
GPL-3.0), used as they are so jplacer's buttons look as OpenPnP's do. A
`_dark` file is the same icon for a dark theme.

`library.svg` (books on a shelf) and `board-source.svg` (a board with parts on it) are jplacer's own, for
a parts or packages table's Source column: drawn in the same flat style, filling their canvas so they read
at a row's height, GPL-3.0 as jplacer is.
